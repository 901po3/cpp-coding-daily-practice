## 🇰🇷 한국어

### 📖 소개
**"AI 시대에 뇌가 녹슬지 않게!"**
이 저장소는 매일매일 꾸준한 알고리즘 트레이닝을 위해 만들어진 C++ 문제 풀이 공간입니다. 생성형 AI가 코드를 짜주는 시대에도, 개발자 본연의 논리적 사고력과 문제 해결 능력을 날카롭게 유지하기 위해 데일리 알고리즘 연습을 진행합니다.

### 🎯 목표
* **매일 1문제 이상 풀이:** 감을 잃지 않기 위한 꾸준한 코딩 루틴 형성
* **C++ 최적화 및 활용:** C++의 성능을 극대화하고 핵심 문법을 탄탄히 다지며 풀이
* **알고리즘 사고력 강화:** 지속적인 두뇌 트레이닝을 통한 '뇌 녹슴' 방지

### 🗂️ 구조
* 해결한 알고리즘 문제들의 소스 코드가 업로드됩니다.
* [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub) 확장을 통해 푼 문제들이 자동으로 푸시(Auto-push)되도록 연동되어 있습니다.

## 🇺🇸 English

### 📖 About
**"Keeping the brain sharp in the AI era!"**
This repository is dedicated to daily C++ algorithm problem-solving practice. In an era where generative AI can write code for us, this project serves as a daily brain workout to maintain and sharpen core logical thinking and problem-solving skills.

### 🎯 Goals
* **Daily Problem Solving:** Build a consistent routine by solving at least one algorithm problem every day.
* **C++ Optimization & Mastery:** Focus on writing efficient code and mastering C++ mechanics and performance.
* **Algorithmic Thinking:** Prevent "brain rust" through continuous cognitive training.

### 🗂️ Structure
* Contains C++ source codes for various algorithm problems.
* Automatically pushed and tracked using the [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub) extension.
